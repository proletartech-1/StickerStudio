PROLETAR PROJECT STICKER GENERATOR (aplikasi web / PWA)

Isi folder ini harus diunggah SEMUA ke hosting HTTPS, lalu dibuka dari alamatnya:
- index.html, manifest.webmanifest, sw.js, proletar-logo.png, icon-192.png, icon-512.png, icon-maskable-512.png
- Proletar Tech · Invoice.html

Cara pasang jadi aplikasi (tanpa Play Store):
1. Unggah folder ke hosting gratis: Netlify Drop (app.netlify.com/drop), GitHub Pages, atau Cloudflare Pages.
2. Buka alamatnya di Chrome HP, lalu menu titik tiga > "Pasang aplikasi" / "Tambahkan ke layar utama".
   Di layar intro juga akan muncul tombol "Pasang sebagai aplikasi".
3. Setelah terpasang, aplikasi bisa dibuka offline (semua file sudah tersimpan).

Mau jadi file APK untuk dibagikan atau Play Store?
- Buka pwabuilder.com, masukkan alamat hosting tadi, pilih Android, unduh paketnya.
- Atau bungkus dengan Capacitor / Bubblewrap bila ingin dikembangkan lebih lanjut.

Catatan: file index.html di dalam folder ini tidak bisa diinstal bila hanya dibuka langsung dari penyimpanan HP (file://). Harus lewat hosting HTTPS.

Batas gambar dan ekspor:
- Tidak ada batas ukuran file atau megapiksel untuk unggahan gambar.
- PNG dibatasi maksimal 25 megapiksel dan sisi terpanjang 12.000 piksel. Jika batas perangkat tercapai saat membuat PNG atau PDF, pilih coba lagi, turunkan resolusi otomatis, atau batalkan.
- Saat resolusi diturunkan, aplikasi mencoba bertahap dan menampilkan ukuran serta DPI hasil akhirnya. PDF lossless dapat beralih ke raster beresolusi lebih rendah hanya jika pengguna memilih menurunkan resolusi.
- SVG lembar menyematkan gambar sumber PNG/JPEG satu kali dan memakai ulang untuk duplikat tanpa menurunkan resolusi; logo dengan efek yang perlu diproses piksel tetap dirender sesuai DPI ekspor.

Penghapus latar:
- "Hapus latar otomatis" mendeteksi warna dari sudut gambar; warna serupa di bagian lain gambar juga dapat ikut terhapus.
- "Magic Eraser" menghapus area dengan warna serupa yang tersambung dengan titik yang diklik. Klik titik lain untuk menambah area yang dihapus.
- Undo/redo tersedia untuk kedua alat (Ctrl+Z dan Ctrl+Y; di Mac Cmd+Z dan Cmd+Shift+Z). Riwayat menyimpan maksimal 8 langkah atau 128 MB agar penggunaan memori tetap terbatas.
- Perbandingan asli dan hasil tersedia lewat slider geser setelah penghapusan selesai.
- Kedua alat berjalan sepenuhnya di perangkat. Hasilnya dapat diunduh atau dikirim ke Studio Warna dan Lembar Stiker.

Upscaler:
- Tab Upscaler memperbesar gambar 2×, 3×, atau 4× sepenuhnya offline menggunakan interpolasi browser berkualitas tinggi atau seimbang.
- Interpolasi memperhalus hasil pembesaran, tetapi tidak menciptakan detail baru seperti upscaler AI. Ukuran hasil dibatasi maksimal 25 megapiksel dan sisi 12.000 piksel; bila perangkat gagal memproses, tersedia opsi coba lagi, turunkan resolusi, atau batalkan.
- Slider perbandingan menampilkan asli dan hasil pembesaran. Hasil PNG dapat diunduh atau dikirim langsung ke Studio Warna maupun Lembar Stiker.

Studio Warna:
- Buat variasi logo secara batch hingga 100 desain; hasil dapat diunduh sebagai ZIP atau PNG satu per satu.
- SVG tanpa gambar berisi kontur potong dan marka registrasi sebagai vektor; pengaturan bentuk, layout, offset, dan marka tetap diterapkan.
- Ekspor mengikuti batas 25 megapiksel dan sisi 12.000 piksel. Ukuran total PNG dalam batch dibatasi 64 MB agar penggunaan memori tetap terkendali.
- Tidak ada batas ukuran file atau megapiksel untuk unggahan.
- Kontrol tab dan unggah gambar mendukung keyboard; preferensi reduced-motion dan indikator fokus keyboard turut dihormati.

Pratinjau File:
- Menu **Pratinjau File** membuka PDF, SVG/SVGZ, PNG, JPG, WebP, GIF, BMP, dan AVIF secara lokal di browser. Untuk CDR/AI/EPS dan sebagian format vektor, aplikasi mencari gambar preview yang tertanam; hasilnya bisa hanya thumbnail. Jika file tidak berisi thumbnail yang dapat dibaca browser, ekspor dari aplikasi asal ke PDF atau SVG lalu buka hasilnya.

Invoice:
- Tab **Invoice** menyediakan editor, cetak/PDF, pengiriman WhatsApp, dan riwayat invoice. Data tersimpan secara lokal dan terpisah dari data alat stiker di browser perangkat ini.

Nama file lembar cetak:
- Templat CDR potret tersedia pada pilihan cepat: halaman 325 × 485 mm dengan bingkai magenta 305 × 435 mm sebagai panduan area print di preview saja, sesuai posisi file referensi (margin sekitar 10 mm kiri/kanan, 32,85 mm atas, dan 17,15 mm bawah). Bingkai tidak diekspor sebagai jalur potong. Marka hitam berupa siku L terbuka di empat sudut bingkai serta dua titik bulat di atas kertas. Preset menjaga jarak aman minimal 5 mm antara stiker dan siku L. Untuk grid, posisi semua bentuk dan ukuran stiker dihitung agar muat sebanyak mungkin; sisa ruang dibagi pada jarak antarstiker tanpa mengurangi jarak minimum dan stiker yang lebih besar dari area bermargin tidak ditempatkan. Stiker bulat memakai zigzag khusus CDR dan sisa ruang dibagi rata, dengan jarak minimum antarstiker tetap terjaga. Kontur magenta pada setiap stiker adalah jalur potong sesuai ukuran stiker; lingkaran batas aman hitam tidak digunakan. Siku L dan titik registrasi tidak dimasukkan ke jalur potong stiker. Preset ini terpisah dari A3+ standar.
- Atur nama pesanan, bahan stiker, laminasi, finishing, dan jenis potongan pada Lembar Stiker.
- PDF, PNG, SVG, DXF, dan PLT memakai nama yang mencantumkan spesifikasi tersebut, ukuran kertas, bentuk, dan ukuran stiker.
- Teks tepi lembar dapat diaktifkan, diubah, atau dikosongkan di Lembar Stiker. Teks dicetak di tengah tepi bawah lembar, bukan pada setiap stiker.
- Metadata adalah label nama file saja. Cocokkan proses laminasi dan potongan dengan percetakan; pilihan nama tidak mengubah garis potong atau memberi efek finishing otomatis.
